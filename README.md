# 『純くんの朝6:30！プクムク・パン詰めパニック』

東京都中野区南台の実在する人気ベーカリー**「パン工房プクムク」**と、看板マスコットキャラクター**「純くん（従業員・純利益）」**をモチーフにした、新感覚の物理パズル＆タイミングアクションゲームの企画・開発リポジトリです。

---

## 🥐 ゲームの概要
* **目的**：朝6:30の開店ベルが鳴るまでに、純くんがパン生地の中に具材を限界まで詰め込み、はちきれんばかりの『極上プクムク状態』を目指す！
* **注意**：欲張りすぎて限界を超えると「大破裂！」して具材が純くんの顔面に直撃。
* **スコア**：単なる点数ではなく、お店にちなんで「本日の純利益：〇〇プク」。

> **【重要・おことわり】**  
> ※本ゲーム内の「パン生地に具材をポンプで注入する」「生地で巨大具材を無理やり包む」などの作り方・ギミックは、**ゲームを面白くするためのフィクション（架空の演出）**です。**実際の「パン工房プクムク」のパンの作り方・製法とは異なります。**

---

## 🍞 確定必須仕様
1. **実在のプクムクぱん完全ラインナップ**
   * クリームぱん、濃厚チョコクリームぱん、プクムクバーガー、じゃがいもぱん、3種のきのこぱん、さばかつバーガー、レーズン食パン、犬専用の無塩ひとくちパン など
2. **ショーケースの『手描きPOPぱん図鑑』**
   * 『極上プクムク！』を達成したパンがガラスケースに並び、実店舗の手描きPOP風イラストとパンのこだわり紹介が読める。
3. **朝6:30の『常連さんリクエスト』システム**
   * お散歩中の犬連れさんや常連のおじさんのリクエストに応えると「常連ボーナス」獲得。
4. **純くんの「今日の一言ポエム」リザルト**
   * 「今日もいい１日になりますように。 純」「純利益」など、Instagramでお馴染みのシュールで温かいポエムが表示される。
